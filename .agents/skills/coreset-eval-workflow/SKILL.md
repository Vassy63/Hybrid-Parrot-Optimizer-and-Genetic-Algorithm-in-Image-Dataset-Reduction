# Coreset & Dataset Reduction Evaluation Workflow

Quy chuẩn đánh giá và đối sánh hiệu năng của tập ảnh rút gọn (Coreset / Reduced Dataset) với mốc chuẩn tập gốc.

## 1. Mục tiêu Đánh giá Khóa luận
Chứng minh tập ảnh rút gọn thỏa mãn 3 tiêu chí khoa học:
1. **Khả năng nén dữ liệu cao (High Compression Rate):** Giảm đáng kể số lượng mẫu ảnh cần lưu trữ.
2. **Duy trì độ chính xác cao (Accuracy Retention):** Độ chính xác khi train trên tập rút gọn tiệm cận tập gốc.
3. **Tính tổng quát hóa qua các kiến trúc khác nhau (Cross-Architecture Generalization):** Hoạt động tốt trên cả 3 mạng có cấu trúc khác biệt: ResNet-18, MobileNetV3, DenseNet-121.

## 2. Cách Thực thi Huấn luyện trên Tập Rút gọn
Truyền đường dẫn thư mục ảnh rút gọn qua tham số `--train_dir`:
```bash
& "D:\Program Files\Miniconda\envs\gamesearcher\python.exe" train.py \
  --model all \
  --train_dir "data/reduced_train" \
  --test_dir "data/seg_test/seg_test" \
  --run_name "coreset_poga_30percent" \
  --epochs 5 \
  --batch_size 64
```

## 3. Ba Chỉ số Học thuật Bắt buộc Phải Tính

### 1. Tỷ lệ Rút gọn dữ liệu (Reduction Ratio - $R$):
$$R = \frac{N_{\text{full}} - N_{\text{reduced}}}{N_{\text{full}}} \times 100\%$$
*(Ví dụ: $N_{\text{full}} = 14.034$, $N_{\text{reduced}} = 4.210 \rightarrow R = 70.0\%$ rút gọn, giữ lại $30\%$).*

### 2. Tỷ lệ Duy trì Độ chính xác (Accuracy Retention Rate - $ARR$):
$$ARR = \frac{\text{Acc}_{\text{reduced}}}{\text{Acc}_{\text{full}}} \times 100\%$$
*(Ví dụ: $\text{Acc}_{\text{full}} = 89.2\%$, $\text{Acc}_{\text{reduced}} = 86.5\% \rightarrow ARR = 96.97\%$).*

### 3. Hệ số Tăng tốc Huấn luyện (Training Speedup - $S$):
$$S = \frac{\text{Time}_{\text{full}}}{\text{Time}_{\text{reduced}}}$$
*(Ví dụ: Train tập gốc mất 210s, train tập rút gọn mất 55s $\rightarrow S = 3.82\times$ nhanh hơn).*
